# Next OS

**C++와 어셈블리로 개발하는 자체 운영체제 프로젝트임.**

Next OS는 부팅 과정과 커널부터 직접 개발하는 운영체제 프로젝트임. 장기적으로 자체 네이티브 API, 그래픽 인터페이스, 앱 시스템 및 스크립트 환경을 갖춘 가볍고 실용적인 운영체제를 만드는 것이 목표임.

> **개발 상태:** 초기 개발 단계임. 아래에 설명된 기능 중 일부는 향후 구현할 계획이며 아직 구현되지 않았음.

## 개발 목표

- 커널과 핵심 시스템 구성 요소를 직접 개발함.

- 이해하기 쉽고 모듈화된 효율적인 구조를 지향함.

- 데스크톱 환경, 창 시스템, 설정, 파일 관리자 및 기본 앱을 개발할 예정임.

- 운영체제 자동화, 시스템 제어 및 앱 개발을 위한 자체 스크립트 시스템인 **ILScript**를 개발할 예정임.

- 네이티브 앱 실행 및 패키지 관리 기능을 추가할 예정임.

- 사용자 데이터를 보호하고 이전 버전으로 복구할 수 있는 업데이트 시스템을 설계할 예정임.

- 장기적으로 Linux 및 Windows 프로그램 호환성을 연구할 예정임.

위 항목은 프로젝트의 목표이며, 현재 모든 기능이 구현됐다는 의미는 아님.

## 기술 스택

| 기술                 | 용도                         |
| -------------------- | ---------------------------- |
| C++                  | 커널 및 시스템 개발          |
| 어셈블리             | 부팅 코드 및 저수준 CPU 설정 |
| GRUB                 | 부트로더                     |
| Docker               | 개발 환경 구성               |
| Make                 | 빌드 자동화                  |
| NASM                 | 어셈블리 코드 어셈블         |
| x86_64 ELF 도구 체인 | 크로스 컴파일 및 링크        |
| QEMU                 | 가상 머신 테스트             |

## 프로젝트 구조

```text
next-os/
├── src/
│   ├── boot.asm
│   ├── kernel.cpp
│   ├── keyboard.cpp
│   ├── keyboard.h
│   ├── types.h
│   ├── vga.cpp
│   ├── vga.h
│   └── linker.ld
├── build/
├── grub.cfg
├── Makefile
├── Dockerfile
├── build.bat
├── README.md
└── README.ko.md
```

`build/`는 빌드 결과물이 생성되는 디렉터리임. 개발 진행에 따라 내부 파일은 달라질 수 있음.

## 현재 구현된 기능

- GRUB을 통한 커널 부팅

- 초기 x86-64 부팅 설정 및 Long Mode 전환

- 초기 메모리 매핑을 위한 페이지 테이블 설정

- C++ 커널 진입점

- VGA 텍스트 모드 출력

- 기본 키보드 입력

- Shift 상태 처리

- Caps Lock 및 Num Lock 상태 처리

- Caps Lock 및 Num Lock LED 제어

- 기본 숫자 패드 입력

- Backspace 처리

키보드 입력과 기타 저수준 시스템은 계속 개발 중임.
